@winm2m/inferential-stats-js

SPSS-level inferential statistics in the browser. A headless TypeScript SDK that runs the Python statistics stack on WebAssembly (Pyodide) — no server, and the data never leaves the page.

npm install @winm2m/inferential-stats-js
  • Package and full API reference on npm
  • Source on GitHub
  • @winm2m/react-stats-ui — React UI built on this SDK
